## 审查发现与修复

| 级别 | 问题与触发 | 处置 |
| --- | --- | --- |
| P1 | 客户重新报价中移除商品，慢响应把旧商品重新放入购物车，可能成交员工已移除的物料 | 重报价期间禁止增删；保留原清单，报价完成后再操作 |
| P2 | 旧行重新报价失败，再加商品会覆盖整单客户报价指纹，让含旧价清单进入提交 | 新增前先完成原清单报价，本次不继续加入；失败继续阻断，不伪造报价完成 |
| P2 | 修改客户关键词后300毫秒防抖期间旧结果仍可选；关闭面板仍会发出待执行查询 | 关键词同步失效旧结果/请求，选择仅限当前结果；关闭取消定时查询，返回旧结果不能覆盖 |
| P2 | 商品搜索同样在防抖期间保留旧词候选，旧词响应可回填新词列表 | 同步失效候选/请求，发起与回填均核关键词，新增回归先红后绿 |
| P2 | 查询客户网络失败被显示成“后台还没有客户档案” | 失败状态与空结果分离，提供重试 |

| P2 | 小数库存固定显示两位，如0.0001显示0.00 | 用字符串去尾零保留精度，不改变库存原值或可售口径 |
