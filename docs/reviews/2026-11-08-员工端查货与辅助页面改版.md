# 员工端查货与辅助页面改版

## 范围

沿codex/staff-experience-redesign，基线e61cbe1，完成查货、库存详情、收银恢复及设备检查四页的代码改版。不增加后端接口/表/模式或资金库存操作。

- 查货：相机扫码入口突出，名称搜索与手输完整编码用两种明确输入方式；切换清空候选/分页/旧货位显示，不自动猜调用另一种查询，旧对象无法继续导航。保留歧义人工选择和批次/货位实际定位。
- 库存：主单位汇总与基准单位货位数量分层，未知单位不猜0，生产/有效期缺失仍显示未知。原批收货量明确不是本货位剩余量；仅展示字符串去小数尾零，不更改原始数量或目标范围。
- 收银核对：原请求摘要与本机空记录分离；只有成功读取本机记录后才能显示“无待核对请求”。进入页绑定当前会话epoch，隐藏时清理页面上的金融视图、不删持久原请求；隐藏/同员工重新登录的旧页不能继续核对。原lookup/cancel屏障/finish事务协调器不改。
- 设备：基础扫码、本机记录和网络状态保留；安全请求号、录音及导航检查默认折叠。失败提示改为先完成核对再使用，避免假称已全局关闭业务提交。录音/网络监听/前后台清理代码保持。

四页复用限定在staff-tools命名空间下的tools.css，由App统一引入；不把相同长样式复制四份，不影响其他业务页局部样式。
