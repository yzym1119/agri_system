# 自动验证门禁补齐

## 对应清单

A2：已有前端/共享/员工测试步骤，但原后端仅mvn test，未开启mysql.it及authority.mysql.it，关键真实MySQL与权限并发测试可能跳过后显示成功。环境变量DB_PASSWORD也不会自动变成测试读取的mysql.it.password系统属性。

本轮改为单次mvn clean verify，显式开启两个测试开关和MySQL连接系统属性。测试仍只使用自身随机临时库，不指定已有业务库。替代原compile、test、skipTests打包三步；verify已经包含打包。

## 报告检查

增加Python标准库检查入口scripts/verify-backend-reports.py，在完整验收之后执行：报告必须非空，测试总数与明细一致，汇总和明细均无失败/错误/跳过。必须包含库存账真实MySQL、旧绩效升级保护、Retail全链三个套件以及权限套件内的MySQL锁等待条件用例。

6项临时XML行为测试从缺入口RED到实现GREEN，覆盖正常、空目录、缺套件、缺权限条件用例、损坏报告、明细跳过/失败不能被汇总零掩盖。Python不引入第三方依赖。

报告不能证明代码/环境新鲜度，必须紧跟当前提交的clean verify使用，不能单独运行旧target后声称本轮测试通过。若重命名关键测试，须同步检查清单并证明仍覆盖原风险。
