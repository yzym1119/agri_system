# 微信模拟器联调收口

本记录补齐上一轮尚未提交的员工端修复，不等于安卓/iPhone真机认证。

- 用户确认使用小程序测试号；仅本机ignored导入工程配置AppID，源码不含AppSecret。
- 开发者工具Stable 2.02.2608060、基础库3.17.5实际运行员工端。原无服务地址的禁用守卫有效；开发构建连接独立本地服务后先被合法域名限制拦住。
- 用户单独授权仅本地模拟器临时“不校验合法域名/TLS/HTTPS证书”，完成后通过界面恢复未勾选；源码和正式构建默认校验未关闭。
- 正常员工登录显示虚构店长/门店；实际搜索商品并打开库存详情，核对现存15袋、原收货20袋、真实厂家批号、生产日期未知和有效期。没有收款、收货、签收或库存写入。
- 本机记录读写删除通过。安全请求号原先失败，临时类型/长度诊断证实返回[object ArrayBuffer]、16字节，而本地instanceof为false。诊断未输出随机内容，定位后已移除日志。
- 跨运行环境ArrayBuffer失败测试先RED，改用ArrayBuffer内建byteLength getter验证真实品牌及精确长度，再转换并复核字节数；仍唯一微信安全随机源，不使用Math.random或伪造请求号。真实模拟器修后显示“安全请求号生成成功”。
- 设备页区分接口不可用、调用失败及数据异常；未知错误保持通用文案，不显示原错误。独审发现toString/constructor/__proto__继承属性误命中后，也已RED→自有属性白名单GREEN。
- 本轮复跑共享51项、员工端54项、类型和微信生产构建通过；没有用这些自动结果替代微信真机/弱网/杀进程验收。
