# POS持久请求领域端口收口

对应清单B2应用层直接依赖基础设施的问题，基线4710378。

## 修改与约束

PosSaleSubmissionService此前直接依赖基础设施PosSaleSubmissionRepository及其嵌套Submission类型。本次在既有domain订单仓储目录增加同名接口与不可变事实record，原基础设施类实现该接口，应用服务改为依赖领域契约。

接口只有reserve/find/complete/cancel四个既有操作，不增加表、缓存、实现副本或第二套可写入口。接口说明明确同一请求行锁先于订单钱货、参加调用方同一事务、UNKNOWN不等于未成交、取消须持久屏障。

原基础设施类保留名称和Spring Bean，只有一个实现；方法体和SQL完全不变，没有加事务或代理层，原JdbcTemplate同Flex连接不变。除接口声明、Override及record类型归属外，基础设施源码与改前文本一致，程序化比较通过。应用服务除两处导入外无改动，原READ_COMMITTED、请求摘要、归属校验和完成结果核对均保留。API仍返回原Result，未暴露新的领域record作为响应。

这是依赖调整，没有发现或声称修复新的收款重复业务缺陷。更简单的仅删除import无法满足编译和持久事实契约；不为这一处引入新模块或通用仓储。
