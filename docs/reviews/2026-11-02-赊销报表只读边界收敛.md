# 赊销报表只读边界收敛

## 清单B3范围

原ReportAnalysisService直接依赖CreditAccountMapper和CreditRepaymentLogMapper，在工作台构造今日新赊销查询、在风控页构造欠款/逾期/月度及原来源相关子查询。新增CreditReportQuery与不可变CreditRiskFacts，将这两类读取放到基础设施实现，复用原Flex Mapper和原外层只读事务；没有第二数据源、共享缓存、表、锁或写入口。

工作台与风控复用新赊销时间范围查询，显式门店条件和实际租户过滤保持。应用层仍负责空聚合的展示零值、分母和回款率；基础设施只返回原账户与还款来源聚合事实。一个asOf日期用于本次风控的逾期日与月份边界，避免方法内多次取当前日期不一致。

## 业务口径保持

- 总欠款只包含状态1/3且剩余正数的账户；已明确逾期状态3即使到期日未知仍包含。
- 本月新赊销与本月实还流水分别按原创建日期统计；旧债本月还款单列，不能混进本月新增应收的回款率。
- 回款率仍为同批本月新增账户净实还/(净实还+剩余欠款)，按明确归属同账户同店的已退还款扣减；冲欠不是现金还款。
- NULL来源、负数/超额退款、原实还与明确来源不一致仍导致未知回款率，不猜0或100；无有效分母仍未知。
