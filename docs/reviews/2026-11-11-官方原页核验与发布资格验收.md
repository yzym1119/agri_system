# 官方原页核验与发布资格验收

2026-11-11；基线`fbb32960cbd59711e657d9cfee3aa8c90a8a508d`，对应[15号计划](../current/15-农技提问与人工接力实施计划.md)4.2b。原页核验与资格工程已验证，**真实Java官网TLS连通未通过**，没有运行AI入口、客户可见发布或真实模型质量验收。

## 范围与实现

搜索摘要可能概括、过时或含自造内容，不能只凭官网URL把它当原文。本批在原case处理链内增加唯一官方原页端口；不建资料库、聊天表或第二套客户事实，也不要求老板先手录文章。V149—V151不改，无新增迁移，原库、原预览及人工隔离库不升级。

| 环节 | 当前行为 |
|---|---|
| 目的地 | 同一规则限定moa.gov.cn/www.moa.gov.cn、HTTPS、默认端口；拒绝伪后缀/用户信息/查询/片段/编码路径；不跟重定向 |
| 读取 | 默认关闭、匿名GET，无认证/会话/来源头；每页完整响应最多5秒/256KiB，不解压外来压缩体；每worker最多3次原页读取调用，沿同一8秒外发窗口 |
| 正文 | 只解析明确TRS_Editor文章区域，嵌套只取唯一最外层；移除脚本/样式/表单/子框架/明显隐藏内容，不执行JS或加载子资源，不把导航/页脚当正文 |
| 元数据 | head的ArticleTitle、PubDate、Url必需；日期重复/冲突、原URL不符、未知结构、UTF8声明矛盾等拒绝；时间按官网上海时区，不猜缺日期 |
| 许可 | 搜索成功usage先持久；每次原页读取前以原私有claim在同Flex实际READ_COMMITTED事务核原客户主档版本、case/facts、门店、原预算日及SEARCH成功/MODEL未发；许可返回后重算剩余窗口 |
| 上下文 | 搜索摘要只作候选筛选；模型收到的是经核验原页的完整适用段落，继续核三农情/观察主题、专业/隐私/注入；不外发原问题、补充原文、身份/UUID/授权或计价 |
| 原证据 | 记录原页HTML/规范正文SHA256、实际核验时间及24小时资格期限，摘录另保留完整段落与其SHA；原页和候选发布日期须同日 |
| 资格 | 独立V2规则再核原事实、来源、时间、主题、段落与逐字摘录；不凭eligible或verified布尔值放行；旧SEARCH_CANDIDATE结果不能自动升为可信答案 |

8秒是允许发起和完成原页HTTP的共享窗口，数据库许可重核自身可能等待行锁；不宣称已为数据库锁等待实现8秒内取消。等待返回后窗口已过期就不再发GET。免费原页读取不增加收费阶段；搜索/生成仍各最多一次，已派出未知保留最大预占，不因原页失败重搜或重生成。

只新增[jsoup 1.24.1解析依赖](https://jsoup.org/download)，不升级已有依赖、不使用其联网接口。HTTP响应字节限制订阅器从原DeepSeek内类提取共用，原18项协议继续回归，避免两份流取消逻辑。原页正文与日期结构依据[农业农村部公开样本](https://www.moa.gov.cn/xw/zxfb/202609/t20260924_6488137.htm)核对；这是模板样本，不是本系统农技建议。

## 数据与资格格式

证据仍在原entry的`assistant_outcome`处理JSON，最大24KiB，不另建表：`policyVersion=OBSERVATION_QUOTES_V2`、`evidenceOrigin=OFFICIAL_PAGE`、`verifiedDirectFetch`，以及sources/citations。sources含实际标题、URL、publishedOn、verifiedAt、validUntil、文档/正文/完整段落SHA及段落；citations只按sourceId引用逐字短摘录。

`publicationEligible`是推导结果，`published`仍false。它不代替真实会话、原case归属、当前主档/身份授权和完成结果核对；4.3只能取白名单展示字段，不把原处理JSON/段落/哈希全量发给客户端。农情变化、资格过期、来源/摘录不符则资格失效，不沿原UUID另收费刷新。

## 真实失败与修复

1. 未配置原页核验器仍返回REFERENCE，实际54项中1失败后改默认本地HUMAN，不执行搜索/生成。
2. 新端口/资格类缺失编译失败后实现；静态未用导入、测试脚本stdin编码问题属于工具/夹具问题，另行修正。
3. HTML声明GBK但按UTF8接受，实际8项网关中1失败；补HTTP及head声明一致检查。证据标题含U+FFFD仍有资格，实际5项中1失败；补同一字符可靠性门槛。
4. 一次独立只读审查确认P2：许可等待超过窗口后仍使用旧remaining发GET。实际57项中1失败，等待8.059秒后预期fetch0/实际1；改为重核返回后再次计算窗口，修复后定向全过。用例以许可替身真实等待模拟阻塞，不冒称本批刻意让MySQL持锁8秒。审查未运行构建、未修改代码，没有重复派审。

## 官网实际读取：分别记录

- 同一官网URI经curl严格证书校验读取成功，观察到签发者CFCA OV OCA；没有关闭证书检查。
- 真实下载HTML交给生产解析器进行离线模板验证，通过：原页日期2026-09-24，规范正文1509字符，文档/正文SHA已留存；真实原文只在临时目录，不写Git或正式业务库。
- **默认Java读取失败**，独立连接诊断显示SSLHandshakeException→ValidatorException→SunCertPathBuilderException。本机JDK未能建立该站点证书的有效信任路径。未修改系统或JDK信任库，也未引入另一套生产抓取器掩盖差异。
- 因此真实JDK端到端来源读取仍未通过，不能把curl成功、离线解析、测试替身的verifiedDirectFetch=true当作实际Java联网成功。没有真实DeepSeek/Search或付费Fetch请求，没有费用。
